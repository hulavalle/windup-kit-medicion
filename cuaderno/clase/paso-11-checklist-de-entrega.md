# Paso 11. Checklist de entrega

**3 min · tu proyecto.** Marca lo que tienes y apunta lo que falta.

La prueba final vuelve al paso 0. Una pregunta está respondida si tiene filas en la matriz y un sitio donde se lee la respuesta.

*Ejemplo 11.1. Una pregunta de Café Fandango, ya respondida*

| Pregunta | Filas de la matriz | Dónde se responde |
| ------ | ---- | ------------ |
| ¿Qué canal trae ventas? | 8 y UTMs | GA4, exploración libre: compras por grupo de canales de la sesión, con `item_category` distinto de `Suscripción` |

*Plantilla 11.1. Checklist de entrega*

| Pieza | Qué debe tener | Hecho | Qué falta y quién lo hace |
| ------ | ---------- | --- | ---------- |
| Matriz de conversiones | Al menos 3 micro y 3 macro, con evento GA4 y parámetros | | |
| Contenedor publicado en tu WordPress | Etiqueta de Google, píxel de Meta (si lo tienes) y un activador de clic, uno de formulario (si tu web tiene formulario) y uno de evento personalizado | | |
| Registro de QA | Una captura de Tag Assistant y otra de DebugView por cada evento | | |
| Hoja de UTMs | Tres enlaces: email, social orgánico y anuncio | | |
| Preguntas de negocio | Cada pregunta del paso 0 con las filas que la responden | | |

Versión completa: abre tu plantilla para terminar tu proyecto. Sus pasos 7 a 9 llevan tu matriz hasta un contenedor publicado y probado, y su paso 11 cierra la entrega.
